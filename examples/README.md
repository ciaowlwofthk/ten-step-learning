## Output specification

- **Format**: single-file HTML, self-contained styles and inline graphics, no external dependencies, ready to send and archive
- **Readability**: controlled text width, readable on mobile; no page breaks inside tables or cards when printed
- **Structure**: cover block + anchor table of contents + 11 sections for steps 0–10 + cheat sheet
- **Companion**: when a print version is needed, a PDF can be produced and delivered together

## When this skill should not be invoked

- You only want the definition of a concept: a normal answer is enough; starting the ten-step flow wastes effort
- You need operating steps (how to open an account, how to file taxes): that is procedural guidance
- The topic is too narrow to support five perspectives: switch to targeted Q&A

## What these samples deliberately get right

The samples are themselves a demonstration of the quality bar — use them as a checklist:

1. **The ten steps build on each other**, not ten parallel lists — step 2's contradictions come from step 1's conflicts, and step 4 scores the items graded in step 2.
2. **Adjudication states conditions, no fudging** — rulings such as "lump sum vs dollar-cost averaging" and "duration vs quality" state the premises under which each side holds, instead of "it depends on the person".
3. **The verification record is fully filled** — step 0's three columns (conclusion / source / verification date) have no blanks, so readers can review.
4. **Low scores name what is missing** — the 72/74-scoring item states exactly which data category is missing, not "more research is needed".
5. **Pseudo-propositions worth abandoning are named** — the 42-scoring item is recommended for abandonment outright, saving the user time.
6. **5 hands-on projects, 1 observation-only** — observation replaces real trial-and-error, the best value for effort.
7. **Every wrong quiz option gets a diagnosis** — explaining "why you would think that and where it goes wrong", not just the correct answer.
8. **The Feynman section has a retelling check** — 5–7 sentences as the bar, with an interaction hook for "if you cannot explain it, change the story and retry".
9. **Conclusions carry conditions** — finance/health judgements are written as "holds under 〔conditions〕", not causal claims (the samples explicitly correct claims like "dollar-cost averaging always wins" and "the more you remember, the better").
10. **High-stakes domains carry disclaimers** — one each for the finance and health topics, in both body and footer.

## About the numbers in the samples

Numbers in the samples fall into two categories: structural facts (e.g. passive products structurally cost less than active ones, recommended sleep-duration ranges), which are publicly verifiable; and illustrative values set for layout demonstration. In a real run, step 0 verifies all "current facts" online first and records source and verification date in the verification table.
